# LEGENDARY VIDEO EDITOR X31 — subtitles on the immutable long timeline

## Executable changes (source/legendary-video-studio)
- `app/long_jobs.py`: accepts uploaded SRT subtitles for long render when an approved shotlist exists, validates owner path / extension / 2 MiB cap, creates an immutable job-scoped SRT snapshot, and checks its SHA-256 digest before every resume. No credentials stored.
- `app/timeline_render.py`: after cached visual chunks are concatenated, burns the selected SRT into the whole video using FFmpeg/libass, then attaches the music bed once. Thus the SRT uses the complete video's timestamps and does not invalidate cached visual chunks.
- `app/bot_pro.py`: forwards the approved SRT path when the long job uses the fixed timeline.
- `tests/test_x31_long_subtitles.py`: 3 tests including actual two-chunk video with music and SRT across chunk boundary, cache reuse, immutable snapshot/tamper rejection, and no-shotlist validation.

## Limitations
- Video text subtitle overlay requires FFmpeg built with libass. Telegram network integration still not live tested.
- Long SRT currently requires an approved shotlist; legacy automatic long render continues without SRT.
- This does not add animated Arabic titles or AI semantic editing to the long timeline; captions are burned SRT with FFmpeg's default styling.
